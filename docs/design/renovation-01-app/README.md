# Registro app renovation

Before/after case study for a UI renovation.

```
before/      current UI screenshots + annotated analysis (the problems)
after/       renovated UI screenshots (the fixes)
prototypes/  self-contained HTML design boards (the exploration)
NOTES.md     running log, entries paired by name
```

Pairing rule: before and after share the same base name, e.g.
`before/dashboard-home.png` <-> `after/dashboard-home.png`.

Workflow lives in the `ui-renovate` skill. Annotation uses `annotate-screenshot`.
